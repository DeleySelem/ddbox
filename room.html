    ℹ️ Encryption, Signing & Safety

    ML-KEM-1024 (FIPS 203) – Category 5 post-quantum key encapsulation for distributing and rotating the room group key.

    ML-DSA-87 (FIPS 204) – Category 5 post-quantum digital signatures over canonical message envelopes (room, sender, timestamp, ciphertext), with live status badges.

    AES-256-GCM – Encrypts group chat messages client-side and protects `/boot` encrypted page delivery (with PBKDF2-SHA256, 100,000 iterations).

    Key rotation & dedup – Group keys rotate automatically every 5 minutes (`300s`), and monotonic message IDs prevent duplicate renders across reconnects.

    Server & transport – Runs Flask-SocketIO in threading mode (eventlet retired); use HTTPS (e.g., ngrok) for Secure session cookies and transit protection.

    Security & trust caveat: The server generates and holds the group key and page passphrase in memory, so a compromised server could decrypt messages or alter served HTML. Software-only PQ math does not by itself provide FIPS 140-3 module validation or out-of-band identity verification—verify user fingerprints out-of-band.

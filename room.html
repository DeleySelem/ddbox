    ℹ️ Encryption & Safety

    AES-256-GCM – Page encryption using a random passphrase.

    ECDH P-256 – For secure group key distribution.

    AES-GCM – Group key encryption for messages.

    Server‑mediated encryption – The server distributes the group key and relays ciphertexts, but does not decrypt your messages. However, the server does have the group key in memory, so a compromised server could potentially decrypt stored messages.

    No plaintext logs – Only ciphertexts and metadata are stored on the server.

    Key rotation – Group key is automatically rotated every 5 minutes.

    Fingerprints – Each user's public key fingerprint is shown in the user list for verification.
